# גיוס · בית חב״ד רמת אביב ג׳

אפליקציית בת של [גיוס](https://github.com/ygtotlrl-lab/gius) — אותו קוד, בלי הלוואות, רשומות ותקציב אירוע, ועם יומן עבודה; התכנית והדשבורד לפי קטגוריות. הכניסה — בחשבון Google מתוך רשימת המשתמשים.

אפליקציית PWA לניהול גיוס כספים. עברית מלאה, RTL, מותאמת למובייל ולדסקטופ.

**כתובת האפליקציה** — `android.url` שבתצורה.

## הפעלה ראשונה

1. הריצו את `migrations/000_schema.sql` מול פרויקט ה-Supabase
   (`supabase.url` שבתצורה) דרך ה-SQL Editor — הוא הסכימה החיה, והרצה חוזרת
   אינה משנה דבר.
2. במסך ההגדרות: היעד החודשי והשנתי, ושש הרשימות (קטגוריות, סוגי התחייבויות, אמצעי תשלום, שייכויות, שגרירים, תחומי משימות).

## מסכים

- **דשבורד** — מצב החודש מול היעד, היעד השנתי, פילוח לפי קטגוריה, מצב המשימות לכל אחראי ותשלומי החודש.
- **כרטיסים ותשלומים** — חיפוש, סינון ומיון; הכרטיס נפתח בתוך הרשימה עם פרטים, שייכויות, התחייבויות ותשלומים.
- **תכנית** — תכנית גבייה והתרמה לכל חודש, לפי קטגוריות, עם צפי מול בפועל.
- **יומן** — יומן עבודה: חלון לכל קטגוריה ול«משימות כלליות», ארכיון הימים ושיתוף כרטיס היום כתמונה.
- **משימות** — לכל אחראי שלושה שלבים: הרצה · השלמה · חסומה.
- **עוד** — הו״ק (תור ההתרמה בטלפון) והגדרות.

## פיתוח

הקליפה ב-`index.html`, והקוד ב-`app/` וב-`core/` — מודולים שהדפדפן טוען כמות שהם. אין build.

```bash
node tools/guard.mjs       # שומר הדחיפה — חובה לפני כל push
node tools/gen-app.mjs     # מחדש מהתצורה את קובצי הפלטפורמה והאייקונים
```
